# УДЭТ Цахим Платформ (National Drama Theatre Portal)

Энэхүү төсөл нь Улсын Драмын Эрдмийн Театрын үзэгчдэд зориулсан цахим тасалбар захиалга, дижитал стриминг болон аялан тоглолтын мэдээллийн нэгдсэн систем юм.

## 🌟 Үндсэн боломжууд
- 🎟️ Интерактив суудал сонголт (VIP ба Энгийн)
- 💳 QPay төлбөрийн систем ба QR цахим баримт
- 🔄 Тасалбар буцаах ба суудал чөлөөлөх логик
- ⏰ Тоглолт эхлэх шууд тоолуур (Live Countdown)
- 🎬 Цахим тайз (DRM хамгаалалттай онлайн үзвэр)
- ⭐ Үзэгчдийн үнэлгээ, сэтгэгдлийн хэсэг
